# Jira

Usa esta skill cuando la tarea implique redactar o estructurar contenido para Jira.

## Reglas
- Mantener contexto, accion y resultado.
- Evitar texto redundante.
- No inventar claves, responsables ni estados.
- Si falta informacion imprescindible, indicarlo claramente.
